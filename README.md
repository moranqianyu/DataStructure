## 🛠️ 环境说明
1. IDE：Visual Studio 2022
2. 项目类型：空项目，创建`.c`源文件，使用C语言编译
3. 调试工具：VS自带断点调试，观察内存、指针变化
4. 代码标准：C89/C99，适配课本伪代码风格

## ✍️ 学习流程（每章统一执行）
1. 精读课本，理解概念、逻辑结构、存储结构、复杂度分析
2. 将课本伪代码手动改写为VS2022可运行C代码，添加详细注释
3. 多组测试用例验证，重点测试边界情况（空结构、满结构、非法输入）
4. 独立完成课后习题，编写习题源码
5. 编写`notes.md`记录知识点、难点、踩坑bug
6. 提交代码到GitHub，规范commit提交信息

## 📝 Commit提交规范
> 格式：`章节 | 完成内容，备注难点/bug`
示例：

- `Ch05 | 二叉树递归遍历：前/中/后序遍历代码完成`

## 📌 仓库说明

## 📚 学习重点
1. 时间、空间复杂度分析（全书基础）
2. 线性表：顺序表、链表指针操作
3. 栈队列：循环队列判空判满
4. 树：二叉树递归/非递归遍历、哈夫曼树
5. 图：DFS、BFS、最小生成树、最短路径
6. 查找：二分查找、BST、哈希表
7. 排序：八大排序原理、复杂度、稳定性对比
